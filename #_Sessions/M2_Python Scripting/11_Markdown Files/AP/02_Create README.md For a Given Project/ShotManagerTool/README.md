# Shot Manager Tool

## Description
Shot Manager Tool is a Python-based pipeline utility designed to  manage of shots in a production environment. It provides functionality for loading shot data, exporting structured outputs, and offering a simple user interface for interaction. This tool is useful for artists and technical directors working in animation, VFX, or game production pipelines.

---

##  Features
- Load and manage shot-related data  
- Export shot data into structured formats  
- Simple UI for interacting with the tool  
- Modular architecture for easy extension  
- Designed for integration into production pipelines  

---

## Requirements
- Python 3.10 or higher  
- Required Module packages :
  - core.loader
  - ui.main_ui

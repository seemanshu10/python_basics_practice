## 🎯 AP. Creating a User Profile

### Task Objective

In this task, you will:
* Create a professional user profile using Markdown syntax.
* Organize and present your basic details, skills, projects, and contact info.
* Structure the content for clear readability and use of Markdown features.

### Instructions

* Create a new GitHub repository for your profile.
* Inside the repository, create a Markdown file (e.g. profile.md or README.md).
* Use proper Markdown syntax to include the following sections:
    * **Introduction**: Your name, short bio, and a placeholder image URL.
    * **Skills**: A bullet list of at least five skills.
    * **Projects**: A table with project name, description, and a link.
    * **Contact Info**: GitHub link, LinkedIn link, and email.
    * **Fun Fact**: Add one fun fact in a quote block.
* Save and commit the file with a clear message.
* Push the repository to GitHub.
* Submit your repository link for review.

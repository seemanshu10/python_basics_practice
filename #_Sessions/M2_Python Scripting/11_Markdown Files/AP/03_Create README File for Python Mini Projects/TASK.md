## 🎯 AP. Create README File for Python Mini Projects

### Task Objective

In this task, you will:
* Create a Markdown (.md) documentation file for each Python mini project you completed.
* Use Markdown formatting to organize project information clearly.
* Include the minimum required documentation sections for every project.
* Practice writing simple and structured project documentation.

### Instructions
* After completing the Python Fundamentals module, you were given several mini projects to practice programming concepts.
* Now your task is to document each of those projects using Markdown.
* For every mini project, create a separate .md file.
* Each Markdown file must include at least the following sections:
  * Project Title
  * Description
  * Features
  * Installation
  * Usage
  * Requirements
* You may add additional sections if you think they help explain the project better, but the sections listed above are required.

### Sample Output

```markdown
# File Organizer Tool

## Description
A Python script that organizes files in a folder based on file extensions.

## Features
- Detects file types automatically
- Creates folders for different file types
- Moves files into the correct folders

## Installation
1. Download the project files
2. Open the project folder in your code editor

## Usage
1. Place files inside the target folder
2. Run the Python script
3. The files will be organized automatically

## Requirements
- Python 3.8+
```

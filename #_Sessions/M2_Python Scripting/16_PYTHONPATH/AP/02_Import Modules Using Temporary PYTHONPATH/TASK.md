## 🎯 AP. Import Modules Using Temporary PYTHONPATH

### Task Objective
Practice using a temporary PYTHONPATH environment variable in the terminal to import modules stored in different locations.

### Instructions
* Use the same module folders and files created in the previous task.
* Remove the system-level PYTHONPATH environment variable from the Environment Variables settings.
* Ensure the module folders remain in their locations
* Set the PYTHONPATH environment variable temporarily in the terminal session.
* Add both module folder paths in the variable
* Navigate to the folder that contains the main.py script.
* Run the script from the terminal.
* Verify whether both modules import successfully during that terminal session.

### Sample Output
```
model_tools imported
render_tools imported
Both modules imported successfully
```

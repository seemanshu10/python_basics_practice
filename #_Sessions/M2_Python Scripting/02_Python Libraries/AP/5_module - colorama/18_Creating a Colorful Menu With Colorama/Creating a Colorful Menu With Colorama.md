## 🎯 AP. Creating a Colorful Menu with Colorama

### Task Objective

In this task, you will:

* Use the `colorama` library to create a color-coded terminal menu.
* Display a menu with multiple options in different colors.
* Respond to user selections by printing a colored message.
* Create a loop that runs until the user chooses to exit.

### Instructions

* Write a Python script that:
  * Imports the necessary modules from `colorama`.
  * Initializes `colorama`.
  * Displays a colorful menu with options.
  * Prompts the user to select an option.
  * Displays a message corresponding to the selected option in a specific color.

### Menu Options:

* **Option 1**: Red Message
* **Option 2**: Green Message
* **Option 3**: Yellow Message
* **Option 4**: Blue Message
* **Option 5**: Exit

---

### Sample Output

```
1. Red Message
2. Green Message
3. Yellow Message
4. Blue Message
5. Exit
Please select an option (1-5): 2
You have selected the Green Message.  ← (in green)
```

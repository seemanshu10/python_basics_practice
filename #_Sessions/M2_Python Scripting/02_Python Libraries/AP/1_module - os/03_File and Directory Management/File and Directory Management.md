## 🎯 AP. File and Directory Management

### Task Objective

In this task, you will:

* Practice creating directories and files using Python’s `os` module.
* Write content to files programmatically.
* Perform file operations such as renaming and deleting.
* Perform directory operations including creation and deletion.

### Instructions

* Create a new folder named `practice_os`.
* Inside `practice_os`, create three subdirectories: `dir1`, `dir2`, and `dir3`.
* In each subdirectory, create a `.txt` file named `file1.txt`, `file2.txt`, and `file3.txt` respectively.
* Write `"Hello from dir1"`, `"Hello from dir2"`, and `"Hello from dir3"` into the files respectively.
* Rename `file1.txt` in `dir1` to `renamed_file1.txt`.
* Delete `file2.txt` from `dir2`.
* Delete the entire `dir3` directory.

### Sample Output

**Final structure after task completion:**

```
practice_os/
├── dir1/
│   └── renamed_file1.txt
├── dir2/
└── dir3/ (deleted)
```

**Contents of renamed_file1.txt:**

```
Hello from dir1
```

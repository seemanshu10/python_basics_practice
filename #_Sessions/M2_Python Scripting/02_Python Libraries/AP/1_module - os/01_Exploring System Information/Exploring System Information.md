## 🎯 AP. Exploring System Information

### Task Objective

In this task, you will:

* Practice using Python’s built-in `os` module to retrieve key system information.
* Learn to detect OS-specific behavior when fetching uptime.
* Organize and present system data clearly using formatted output.
* Build awareness of commonly accessed system attributes useful in VFX pipeline automation.

### Instructions

* Print the current working directory.
* Display the name of the operating system.
* Show the current user's login name.
* Output all available system environment variables.
* Print the number of CPUs available.
* Detect the platform and calculate the system's uptime accordingly.
* Use readable print formatting for all outputs.

### Sample Output

```
Current Working Directory: /Users/student/vfx_project  
Operating System Name: posix  
User Login Name: student  
Environment Variables: {'PATH': '/usr/bin:/bin:/usr/sbin', 'HOME': '/Users/student', ...}  
CPU Count: 8  
System Uptime: 123456.78 seconds  
```

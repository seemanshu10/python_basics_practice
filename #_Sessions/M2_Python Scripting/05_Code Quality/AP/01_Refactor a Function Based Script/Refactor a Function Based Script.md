## 🎯 AP. Refactor a Function Based Script

### Task Objective
In this task, you will:
* Refactor a Function based script to improve its overall code quality
* Apply consistent naming, modular structure, and clear documentation
* Replace hardcoded values with constants and handle invalid input
* Ensure the code is easy to read, maintain, and reuse

### Instructions
* Use the raw script provided below as your starting point
* Apply code quality principles to refactor and organize the code
* Improve naming, formatting, spacing, and documentation
* Add constants where appropriate instead of using hardcoded values
* Validate inputs to prevent unexpected errors
* Remove any commented-out or unnecessary code
* Ensure your final version reflects clean, production-ready code standards
* Script was given in **main.py** file.
* update refactor code in **refactor.py** file

### Sample Output (Expected Behavior)
```
Total price before discount: 100.0
Discount applied: 10.0
Final price after discount: 90.0
```

If invalid values are used:
```
Error: Price and quantity must be positive numbers.
```

## 🎯 AP. Analyze PATH ENV Variable

### Task Objective

In this task you will:
* Retrieve the PATH environment variable using Python.
* Display the entire PATH value in the terminal.
* Break the PATH string into individual directory entries.
* Print each directory separately to clearly inspect the system search paths.

### Instructions
* Create a Python script that reads the system PATH environment variable and displays it in a readable way.
* The script should first display the raw PATH value retrieved from the environment variables.
* Then it should process the value so that each directory contained inside the PATH is displayed individually.

### Sample Output

```
Raw PATH Value:
C:\Windows\system32;C:\Windows;C:\Program Files\Git\cmd;D:\Python3_9_7\Scripts\;D:\Python3_9_7\

Directories Found in PATH:
C:\Windows\system32
C:\Windows
C:\Program Files\Git\cmd
D:\Python3_9_7\Scripts\
D:\Python3_9_7\
```

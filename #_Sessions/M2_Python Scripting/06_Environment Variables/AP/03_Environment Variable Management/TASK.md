## 🎯 AP. Environment Variable Management

### Task Objective
In this task, you will:
* Read and display an existing environment variable using Python.
* Create a new environment variable inside a Python script.
* Modify the value of the created environment variable.
* Remove the environment variable from the current session.
* Verify each step by printing the variable value.

### Instructions
* Read and print an existing environment variable (e.g., PATH).
* Set a new environment variable named MY_VAR with a value of HelloWorld.
* Verify and print the value of the newly set environment variable.
* Modify the value of MY_VAR to HelloPython.
* Verify and print the updated value of MY_VAR.
* Delete the environment variable MY_VAR.
* Verify and print the deletion status of MY_VAR.

### Sample Output

```
Existing PATH: C:\Windows\system32;C:\Windows;C:\Program Files\Git\cmd
MY_VAR set to: HelloWorld
MY_VAR value: HelloWorld
Updated MY_VAR to: HelloPython
Updated MY_VAR value: HelloPython
MY_VAR deleted successfully.
```

## 🎯 AP. Refactor a Class Script

### Task Objective
In this task, you will:
* Refactor a class-based script to improve its overall code quality
* Apply clear naming, structure, and documentation across all classes and methods
* Replace hardcoded values with constants and validate input data
* Prepare the code to be readable, maintainable, and ready for team use

### Instructions

* Use the raw script provided below as your starting point
* Refactor all classes and their methods to follow code quality best practices
* Rename all unclear class names, method names, and variable names
* Add necessary docstrings, comments, and structure to make the code maintainable
* Split any unclear logic into smaller, self-contained methods if needed
* Use class or module-level constants for values like discount percentages
* Ensure all final output is informative, consistent, and clean
* Code will provided in main.py file do check it.

### Sample Output (Expected Behavior)
```
Total before discount: 150.0
Discount applied: 15.0
Final amount: 135.0
```
**If invalid values are used:**
```
Error: Price and quantity must be non-negative numbers.
```

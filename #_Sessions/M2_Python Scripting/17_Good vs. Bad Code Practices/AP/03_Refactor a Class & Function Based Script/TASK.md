### Task Objective

In this task, you will:
* Improve the overall quality of a script that uses both classes and functions
* Organize logic into clearly defined, reusable structures
* Ensure the code is readable, maintainable, and easy to extend
* Apply input validation, proper naming, and documentation standards
* Refactor existing logic to meet professional code quality expectations

### Instructions

* Start with the raw code provided below
* Refactor the class and all functions using code quality best practices

* Ensure final output is clean, readable, and logically organized
* Code will provided in main.py file do check it.

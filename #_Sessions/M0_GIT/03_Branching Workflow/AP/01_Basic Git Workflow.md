## 🎯 AP. Basic GIT Workflow

### Task Objectives
* Create a new public GitHub repository in your personal GitHub account.
* Clone the repository to your local machine.
* Open and manage the repository using Visual Studio Code.
* Create a new file and add content to it.
* Stage, commit, and push changes to the remote repository.
* Verify changes on GitHub.
* Submit your public repository link for review.

### Instructions
* Create a Public Repository:
  * Name the repository exactly: git-basics-practice.
  * Set the visibility to Public
  * Do not initialize with a README, license, or .gitignore file.
* Clone the Repository:
  * Use the git clone command to download the repository to your local machine.
* Open in VS Code:
  * Launch VS Code and open the cloned git-basics-practice folder.
* Create a New File:
  * Inside the project folder, create a file named: hello_git.py.
  * Add a basic print statement in the file.
* Stage and Commit the File:
  * Stage the new file
  * Commit the file with a message: Add hello_git.py with a welcome message.
* Push Changes to GitHub:
  * Push your commit to the main branch of the remote repository.
* Verify and Submit:
  * Go to your GitHub repository in a browser.
  * Confirm that hello_git.py is visible in the main branch.
  * Submit your public repository link for instructor review.

### Reminder:
* You will continue using this same repository (git-basics-practice) for all upcoming APs for this Topic
* Keep your repository organized and ensure future tasks are pushed to the same repo.

## 🎯 AP. Create Branch and Pull Request

### Task Objectives
* Create and push a new Git branch to the existing git-basics-practice repository.
* Open a new Pull Request (PR) on GitHub from your branch to the main branch.
* View and rename the PR using GitHub’s web interface.
* Explore the file changes and commit history within the PR.
* Submit the Pull Request link only (do not merge).

### Instructions
* Create a New Branch:
  * Inside the existing repository git-basics-practice, create a new branch named exactly: feature/pull-request-practice.
* Make File Changes:
  * Add a new file named pull_request_note.txt and write a brief note like: "This file was added for pull request practice."
* Commit and Push:
  * Stage and commit the changes with a message such as: Add pull_request_note.txt for PR workflow.
  * Push the new branch to GitHub.
* Open a Pull Request (PR):
  * On GitHub, open a new PR from feature/pull-request-practice into main.
* Update the PR:
  * Rename the PR to: Practice Pull Request: feature/pull-request-practice.
* Review the PR:
  * Use GitHub’s interface to:
    * View file changes.
    * Check the commit history tab.
* Submit Your Pull Request Link:
  * Do not merge the PR.
  * Copy the URL of the PR (e.g., [https://github.com/your-username/git-basics-practice/pull/1](https://github.com/your-username/git-basics-practice/pull/1)) and submit it for instructor review.

### Sample Output
pull_request_note.txt
```
This file was added for pull request practice.
```
**GitHub Interface:**
* Open PR titled: Practice Pull Request: feature/pull-request-practice
* One commit visible in the PR
* File change listed clearly

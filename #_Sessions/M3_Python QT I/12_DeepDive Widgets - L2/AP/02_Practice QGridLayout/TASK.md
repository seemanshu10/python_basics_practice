## 🎯 AP. Practices QGridLayout

### Task Objective

By completing this task, you will:

* Create a `QWidget` window with a `QGridLayout`
* Add labels and input fields for name and email
* Add a submit button aligned to the layout
* Control widget spacing, margins, and column/row stretching
* Style the input fields using `setStyleSheet`


### Instructions

* Build a `QWidget`-based window
* Use `QGridLayout` to position widgets in a grid
* Add two `QLabel` widgets: one for “Name” and one for “Email”
* Add two `QLineEdit` widgets for user input
* Add a `QPushButton` labeled “Submit”
* Position the widgets using specific row/column values
* Use row/column spans where needed for better alignment
* Add spacing and margins to the layout using layout methods
* Stretch the last row and column so the form feels responsive
* Apply basic themed styling to both input fields

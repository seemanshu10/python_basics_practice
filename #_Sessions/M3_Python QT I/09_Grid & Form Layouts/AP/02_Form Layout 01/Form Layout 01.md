## 🎯 AP. Form Layout 01

### Task Objective

In this task, you will:

* Build a GUI form using QFormLayout in PySide2 to neatly align labels and input fields.
* Use QLineEdit for text-based input fields with appropriate placeholder text.
* Use QComboBox for fields that require dropdown selections.
* Arrange all widgets in a vertically stacked form layout, following standard UI conventions.

### Instructions

* Create a window titled "Form Example".
* Use a QFormLayout to pair each label with an appropriate input widget.
* Add the following input fields using QLineEdit, and set placeholder text (e.g., "Enter Address"):
  * Address, City, Zip, UPB, Interest Rate, P&I, Term, Original Balance, Note Date, Last Paid To, Next Due Date, Maturity Date
* Add the following dropdowns using QComboBox with the specified options:
  * State: "Select State", "CA", "NY", "TX", "FL"
  * Asset Type: "Type 1", "Type 2", "Type 3"
  * Note Status: "Active", "Inactive", "Pending"
* Ensure all fields are properly aligned and follow a clean, professional layout.

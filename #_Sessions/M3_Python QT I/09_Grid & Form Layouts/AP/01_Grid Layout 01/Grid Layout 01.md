## 🎯 AP. Grid Layout 01

### Task Objective

In this task, you will:
* Build a calculator-style GUI using PySide2.
* Use a QGridLayout to arrange buttons in a structured grid layout.
* Organize your application using a class that inherits from QWidget.
* Create a functional layout that mimics a standard calculator interface with all required buttons in the correct positions.

### Instructions
* Create a window titled "Calculator".
* Use a QGridLayout to position all buttons in a structured grid.
* Create the following buttons and arrange them in rows and columns:
  * Row 0: Cls, Bck, Close
  * Row 1: 7, 8, 9, /
  * Row 2: 4, 5, 6, *
  * Row 3: 1, 2, 3, -
  * Row 4: 0, ., =, +
* Implement the GUI inside a class that inherits from QWidget.
* Ensure all buttons are evenly spaced and properly aligned in the grid layout.
* You are not required to implement button functionality — layout only.

## 🎯 AP. Asset Manager with Toolbar File Menu

### Task Objective:

* Create a QMainWindow-based application for asset management.
* Add a menu bar to the window with a "File" menu.
* Add two actions under the File menu: "Open" and "Save".
* Trigger status bar messages when each action is selected.
* Ensure the menu is properly integrated and responds to user input.

### Instructions:

* Build a QMainWindow application titled Asset Management.
* Add a menu bar with a File menu containing:
  * An Open action that simulates opening an asset.
  * A Save action that simulates saving an asset.
* When the user selects:
  * Open → display "Opening Asset..." in the status bar.
  * Save → display "Saving Asset..." in the status bar.
* Add a simple central widget (e.g. label or layout) to represent the dashboard.
* Make sure the File menu appears in the window’s menu bar and is fully functional.

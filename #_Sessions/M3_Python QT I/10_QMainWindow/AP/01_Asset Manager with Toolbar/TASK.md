## 🎯 AP. Asset Manager with Toolbar 

### Task Objective:

* Build a QMainWindow interface for an asset management tool.
* Add a top-aligned QToolBar with two interactive actions: Add Asset and Delete Asset.
* Connect each toolbar action to a corresponding function that updates the status bar.
* Display status messages ("Asset Added", "Asset Deleted") when actions are triggered.

### Instructions:

* Create a QMainWindow-based application titled Asset Manager.
* Add a toolbar that contains two actions:
  * One labeled Add Asset
  * One labeled Delete Asset
* The toolbar must be clearly visible and appear at the top of the window.
* Clicking Add Asset should update the status bar with the message "Asset Added".
* Clicking Delete Asset should update the status bar with the message "Asset Deleted".
* Add a central widget with a simple label to represent the main dashboard area.

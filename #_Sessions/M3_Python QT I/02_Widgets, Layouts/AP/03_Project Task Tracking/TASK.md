## 🎯 AP. Project Task Tracking

### **Task Objective**

In this task, you will:
* Build a PySide2 GUI to manage task tracking for a VFX project.
* Allow users to input new task names and mark tasks as completed.
* Maintain a visual list of all submitted tasks with their completion status.
* Use basic form controls like input fields, checkboxes, buttons, and a list widget.

### **Instructions**
**Note: Create Only GUI not Functionality**

* Create a main window titled **"VFX Project Task Tracker"**.
* Add a **QLineEdit** where the user can enter a task name.
* Add a **QCheckBox** labeled **"Task Completed"** to mark task status.
* Add a **QPushButton** labeled **"Add Task"**:
  * When clicked, the task should be added to a list with the entered name and the completion status.
  * After adding the task, the input field should clear and the checkbox should reset.
* Add a **QListWidget** to display all added tasks with their current status (e.g., "Completed" or "Not Completed").

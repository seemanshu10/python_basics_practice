## 🎯 AP. File Management GUI

### **Task Objective**
In this task, you will:
* Build a simple PySide2 GUI application for managing file paths in a VFX pipeline.
* Create a user interface to input a file path and display file-related messages.
* Simulate file operations such as opening and deleting files using user interaction.
* Practice using `QLineEdit`, `QLabel`, `QPushButton`, layouts, and signal-slot connections.

### **Instructions**
**Note: Create Only GUI not Functionality**

* Create a main application window titled **"File Management Tool"**.
* Add a **QLineEdit** for the user to input a file path.
* Add a **QLabel** to display messages to the user (e.g., file opened, file not found).
* Add a **QPushButton** labeled **"Open File"**:
  * When clicked, it should check if the file exists and update the label with a message.
* Add another **QPushButton** labeled **"Delete File"**:
  * When clicked, it should simulate deleting the file by printing a message to the console and updating the label.
* Use a **QVBoxLayout** to organize all the widgets vertically.

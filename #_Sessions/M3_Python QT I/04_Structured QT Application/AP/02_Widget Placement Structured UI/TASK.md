## 🎯 AP. Widget Placement Structured UI

### **Task Objective**

In this task, you will:
* Create a PySide2 GUI window with manually positioned widgets.
* Use the `move()` method to place widgets at specific coordinates.
* Build a label and a button inside the window with precise control over their placement.
* Implement a basic event that updates the label when the button is clicked.


### **Instructions**

* Create a main window using `QWidget`.
* Set a window title and define a fixed window size.
* Add a `QLabel` to display a default message and position it manually using `move()`.
* Add a `QPushButton` with a label (e.g., "Click Me") and position it using `move()`.
* Define a function to update the label text when the button is clicked.
* Connect the button’s `clicked` signal to the defined function.
* Run the application and display the window.

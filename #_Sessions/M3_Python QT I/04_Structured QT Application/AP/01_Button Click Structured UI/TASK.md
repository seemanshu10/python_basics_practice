## 🎯 AP. Build Multi-Button GUI with Dynamic Actions

### **Task Objective**
In this task, you will:
* Build a PySide2 GUI with two interactive buttons.
* Create a layout that displays a message based on which button is clicked.
* Practice using multiple `QPushButton` widgets to trigger different actions.
* Apply signal-slot connections to manage independent behaviors for each button.


### **Instructions**
* Create a main window using `QWidget`.
* Set a window title appropriate for a multi-button GUI.
* Use a `QVBoxLayout` to arrange all widgets vertically.
* Add a `QLabel` at the top to display dynamic text based on user input.
* Add two `QPushButton` widgets with different labels.
* Define a separate function for each button that updates the label with a unique message.
* Connect each button's `clicked` signal to its corresponding function.
* Launch and display the window using the application event loop.

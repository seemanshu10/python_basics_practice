## 🎯 AP. To-Do List App

### **Task Objective**

In this task, you will:

* Build a basic To-Do List user interface using PySide2.
* Capture text input from the user and add it to a list widget.
* Use signals and slots to connect the button with task addition logic.
* Clear the input after adding each task.

### **Instructions**
* Create a main window using `QWidget`.
* Use `QVBoxLayout` to vertically stack all elements.
* Add a `QLabel` and a `QLineEdit` for entering new tasks.
* Add a `QPushButton` labeled **"Add Task"**.
* Add a `QListWidget` to display the added tasks.
* Connect the **"Add Task"** button to a function that:
  * Reads text from the input field.
  * Adds the text to the task list.
  * Clears the input field.

## Task 11 - Load UI File After Converting

### ✔️ Objective
Use the same `.ui` file created in Task 9, convert it into a Python file, and use that generated UI class in the application.

### ✔️ Requirements
* Use the same `.ui` file created in Task 9.
* Convert the `.ui` file into a Python file.
* Import the generated Python UI class into the main application.
* Create a main application class and use the generated UI class inside it.
* Connect the widgets and actions to Python functions.
* Make the application functional like the final version:
    * Save note
    * Clear fields
    * Choose color
    * Choose font
    * Change title
    * Export note
    * About dialog
* Use the widget and action object names exactly as defined in the `.ui` file.
* The app should run using the converted Python UI file, not by dynamically loading the `.ui` file.

### ✔️ Learning Goal
By completing this task, you will practice:
* converting `.ui` files into Python using pyside2-uic
* combining Designer UI with custom logic
* connecting signals and slots

### ✔️ Sample Output
* The app output will remain the same as Task 8.
* There are no UI changes also no functionality changes in this task.

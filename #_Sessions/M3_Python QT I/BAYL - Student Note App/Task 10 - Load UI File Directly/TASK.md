## Task 10 - Load UI File Directly

### ✔️ Objective
In this task,
* Use the same `.ui` file created in Task 9 and load it dynamically in Python.
* load the `.ui` file using QUiLoader and then connect the widgets and actions from Python.

### ✔️ Requirements
* Use the same ``.ui` `file created in Task 9.
* Load the `.ui` file dynamically at runtime using:
    * `QFile`
    * `QUiLoader`
* Access the widgets using their object names from the `.ui` file.
* Connect the buttons and menu actions to their respective functions.
* Make the application functional like the final version:
    * Save note
    * Clear fields
    * Choose color
    * Choose font
    * Change title
    * Export note
    * About dialog
* Use the same object names that were assigned in Qt Designer.
* Do not convert the `.ui` file into a Python file
* The app should run directly using the `.ui` file.
* Use script-relative icon paths from the img folder.

### ✔️ Learning Goal
By completing this task, you will practice:
* loading `.ui` files dynamically using QUiLoader
* accessing Designer widgets in Python
* connecting signals and slots
* separating UI design and Python logic

### ✔️ Sample Output
* The app output will remain the same as Task 8.
* There are no UI changes also no functionality changes in this task.

# Task 12 : Document, Demo, and Showcase

## Objective

You have completed building your **Student Notes Pro** application. In this task, you will prepare your project for showcasing.

Your goal is to make the project easy to understand, easy to run, and easy to present to others. You will add code documentation, create project documentation, record GIFs, make a demo video, and write a LinkedIn post sharing your learning experience.

---

## What You Will Practice

By completing this task, you will learn how to:
1. Add useful `docstrings` to your Python code.
2. Write a clean `README.md` file for your project.
3. Create short `GIFs` to showcase important features.
4. Record a demo `video` explaining your application.
5. Reflect on your `learning journey` and share it professionally on `LinkedIn`.

---

## Part 1: Add Code Documentation

Add docstrings to:
1. The `MainWindow` class.
2. The `__init__` method.
3. Every major method in the class.
4. Any method where the purpose is not immediately obvious.

#### Rules
* Do not change the app’s main functionality.
* Keep docstrings simple and beginner-friendly.
* A good docstring should explain what the method does, not repeat every line of code.
* Add comments only where they help explain important logic.

## Part 3: Create GIFs for Showcase
Create short GIFs that show the important features of your app.
Create at least **3 GIFs**:

#### GIF 1: App Overview

Show:
* Opening the app.
* The main layout.
* Name, subject, category fields.
* Notes area.
* Buttons, menu bar, and toolbar.

#### GIF 2: Writing and Customizing Notes

Show:
* Entering name, subject, and category.
* Writing a note.
* Changing font.
* Changing text color.

#### GIF 3: Exporting a Note

Show:
* Writing note content.
* Clicking export.
* Saving the file.
* Showing the success message.

#### GIF Guidelines
* Keep each GIF short: 10–20 seconds.
* Keep the screen clean.
* Make sure text is visible.
* Do not include personal or sensitive information.
* Store GIFs in a folder named: assets/
Example:
```text
assets/app-overview.gif
assets/customize-note.gif
assets/export-note.gif
```
